Réglages du cockpit

Le bandeau de statuts (7 dp) affiche trois zones colorées : GPS (fix), CALAGE (horizon calibré par appui long) et DONNÉES (cartes & VAC à jour). Vert = OK, rouge = action requise. Indépendant par tableau de bord.

Fond du cockpit

Trois modes : Défaut (pas de fond), Couleur (palette + hex + opacité 0–100%), ou Texture (grille de textures + opacité 0–100%). Les vignettes affichent un badge d'opacité quand opacité < 100%.

Fond du cockpit

Grille (2 colonnes)

Choisissez un instrument par case (tapez dans le champ pour filtrer la liste). Options ouvre la couleur, le biseau, la gestion de la cellule (Large / Haut / Séparer), « Masquer le titre », l'aspect du titre (Défaut / Couleur / Texture) et le fond de l'instrument (Défaut / Couleur / Texture). Les flèches ↑/↓ réorganisent les lignes.

Exporter
