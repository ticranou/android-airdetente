AirDetente

Aéroclub Air détente · ULM · LFAJ Argentan

Checklists, cockpit EFIS, terrains & météo, carte mobile — une seule application, dans votre poche.

Ce que fait l'application

  • Checks — exécution guidée des checklists : cochage dans l'ordre, progression, enchaînement.
  • Cockpit EFIS — tableaux de bord configurables (grille 2×N à fusion de cellules), instruments alimentés par les capteurs.
  • Raccourcis (CMNSCT) — 3 slots pour accès rapide à vos instruments ou tableaux de bord préférés.
  • Focus mode — pinch-to-zoom (deux doigts écartés) pour zoomer sur un instrument avec compte à rebours auto-fermeture.
  • Terrains / VAC — aérodromes par proximité, cartes VAC, météo METAR/TAF.
  • Carte mobile — fond de carte VFR hors-ligne (MapLibre + OpenAIP), trace, route, radar météo, vent au FL20.
  • Trafic Safesky (ANLTRF) — radar de trafic aérien en temps réel, 5 nm, niveaux de danger.
  • Proximité sol TAWS (ANLPRX) — hauteur AGL calculée sur MNT SRTM (~30 m), alertes CAUTION / WARNING / PULL UP.
  • Enregistreur de vol (ANLFDR) — buffer glissant GPS + capteurs, export KML / GPX / CSV.
  • Réglages — onglets Affichage, Cockpits, Appareils, Checklists, Terrains, Aide ; import/export.
  • Compatibilité matérielle — un test au démarrage vérifie les capteurs (gyroscope, baromètre, GPS) et prévient si certaines fonctions seront indisponibles.
