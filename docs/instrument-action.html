Action

Interrupteur virtuel d'action moteur (démarrage / arrêt), avec ses effets sur la session de vol

Possibilités

  • Jauge ronde affichant le libellé de l'action ("Démarrage" / "Arrêt moteur"). Le titre "ACTION MOTEUR" est rendu par la pastille de titre standard en haut du cadran (masquable via Options ▸ "Masquer le titre" dans la case du cockpit)
  • Interrupteur basculant : position gauche OFF (gris) / droite DONE (vert)

Gestes supportés

Appui long : Choix du type d'action. La dialogue propose également un bouton "Effacer" pour retirer l'action assignée et un bouton "Fermer" pour annuler
Double-tap : Basculement DONE ↔ OFF, ce qui déclenche les effets sur la session de vol

Effets au basculement de l'interrupteur

  • Démarrage / DONE : Lance l'enregistreur de vol, cale l'horizon (EFIS, horizons), démarre le suivi carburant, horodate le départ, puis ouvre trois dialogues séquentiels :
    1. Carburant embarqué — Saisie du volume initial
    2. Étalonnage altimétrique — Calibration de l'altimètre
    3. Horamètre départ — Saisie du relevé de départ (format NNN.NN), stocké dans les instruments ANLHRM / NUMHRM
  • Démarrage / OFF : Arrête l'enregistreur et le suivi, efface l'heure de départ
  • Arrêt / DONE : Arrête l'enregistreur, horodate l'arrivée, puis ouvre deux dialogues séquentiels :
    1. Horamètre arrivée — Saisie du relevé de fin de vol (format NNN.NN, optionnel — "Annuler" passe à l'étape suivante)
    2. Dossier de vol — Récapitulatif complet de la session (horaires, durée, altitude calée, statistiques FDR, et section Horamètre si au moins un relevé est renseigné)

Note

Chaque case ANLACT mémorise son action et son état DONE/OFF. Les horaires alimentent l'instrument Session de vol (NUMFGT).
