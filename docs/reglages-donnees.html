Possibilités

Fond de Carte

  • Télécharger / mettre à jour la carte VFR hors-ligne (fond + données OpenAIP), avec vérification des mises à jour.
  • À réaliser de préférence en Wi-Fi (volume de données important).

Cartes VAC

  • Télécharger les PDF VAC pour une consultation hors-ligne.
  • Vérifier les mises à jour des cartes selon le cycle AIRAC configuré dans l'onglet Terrains — désormais calculé automatiquement d'après la date, pré-rempli et modifiable, avec un bouton « Aujourd'hui ».

Sauvegarde / Restauration

  • Sauvegarder mes données : exporte l'ensemble de la configuration (appareils, checklists, cockpits, terrains, réglages).
  • Restaurer mes données : réimporte une sauvegarde précédemment exportée.
  • Via le sélecteur de fichiers Android (SAF).
