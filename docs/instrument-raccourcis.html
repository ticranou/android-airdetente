Raccourcis

NUMSCT — 3 accès rapides : instruments ou tableaux de bord

Possibilités

  • Bandeau horizontal de 3 slots placé en haut ou en bas d'un tableau de bord.
  • Chaque slot peut pointer vers un instrument (affiché en blanc), un tableau de bord (affiché en bleu) ou une station météo d'un terrain (affichée en vert).
  • Le label affiche le nom lisible de l'instrument, sans indication de taille (ex. : Altimètre au lieu de Altimètre (100%-3L)).
  • Tap sur un slot non vide → ouvre l'instrument / le tableau de bord en plein écran (bouton Fermer), ou le détail METAR/TAF pour une station météo.
  • Le tableau de bord ciblé peut être masqué du cockpit principal (« Afficher dans le Cockpit » décoché) — il reste accessible via le raccourci.
  • Slots vides affichés comme -----.

Configurer un slot

  • Appui long sur un slot → dialogue de choix du type :
    Tableau de bord (>>) → naviguer vers un tableau du pager.
    Tableau de bord (Focus) → ouvrir un tableau en plein écran.
    Instruments → sélecteur d'instrument habituel (toutes familles).
    Terrain (Carte VAC) → ouvrir la carte VAC d'un terrain.
    Terrain (Station Météo) → choisir parmi les terrains disposant d'une station météo ; le tap ouvre le METAR/TAF.
  • La configuration ne touche que le slot pressé ; pas d'avance automatique.

Gestes supportés

Appui long : configurer le slot
↗ Tap : ouvrir l'instrument / tableau de bord

Cas d'usage typiques

  • Tableaux de bord dédiés à des phases de vol (décollage, croisière, approche) accessibles en un tap.
  • Instruments favoris toujours à portée depuis n'importe quel tableau de bord.
